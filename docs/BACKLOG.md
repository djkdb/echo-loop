# Echo Loop — 백로그

지금 마일스톤 범위 밖이라 미뤄 둔 결정·개선. 해당 시점이 오면 여기서 꺼내 판단한다.

## 퍼즐 설계

- **패러독스(고스트 붕괴)가 자연 발생하려면 "닫는" 요소가 필요하다.**
  압력판(OR) → 문, 끼임 방지만 있는 지금은 루프가 쌓일수록 문이 "더 열리는" 쪽으로만 변해서,
  녹화 때 열려 있던 문이 재생 때 닫혀 있는 상황이 생기지 않는다.
  레버(지금의 내가 문을 닫음) 또는 반전 문(`inverted`: 신호가 오면 닫힘)이 들어와야 붕괴가 플레이 중에 나온다.
  - 1-5 "막지 마라"는 이 요소 도입 후 설계한다.
  - 2주차 레버와 함께 레버/반전 문 중 무엇으로 갈지 결정한다.

## 촬영

- **붕괴 장면 촬영용 디버그 키**(고스트 강제 붕괴 등): 릴스 촬영 시점에 검토. 입력 액션이 새로 필요하다.

## 배포

- **폰트 서브셋**: `assets/fonts/NotoSansKR-Bold.otf` 4.6MB → 필요한 글자만 남겨 약 1MB. 웹 배포 직전에.

## 연출

- **고스트가 위로 움직일 때 위에 선 Player 발밑을 최대 15px 파고든다.**
  sync_to_physics 고스트의 이동은 물리 스텝에 반영되고 Player는 그 플랫폼 속도를 다음 틱에 받는 엔진 구조상 1틱 지연이 있다.
  위치 재생·결정론에는 영향 없음. 연출 단계에서 재검토.
